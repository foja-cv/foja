# Foja

Foja is the CV editor I am building on top of what I learned here: the same idea of writing
every entry once and picking them per job with a profile, but with forms instead of JSON files,
[Typst](https://typst.app) instead of LaTeX, and a live preview that is the real output. It runs
entirely in the browser, keeps the data on your own computer, and exports to PDF, JPG, Word,
Typst, LaTeX, Markdown and JSON.

I started planning it in this file and moved the plan to Foja's own repository on 2026-10-30,
once it was clear the editor would be a project of its own. The plan, and how each stage turned
out, continue in <https://github.com/foja-cv/foja>, in `docs/plan.md`.
